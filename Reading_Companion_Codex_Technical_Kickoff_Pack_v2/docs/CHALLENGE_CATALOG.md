## Global rules
- Even year → Version A; odd year → Version B.
- One active version per calendar year; yearly configuration is snapshotted.
- Confirmed prompts become occupied sequentially; challenges are independent.
- Semantic automatic suggestions require reliable evidence and ≥70% confidence.
- Analyze all eligible free prompts; show only the best proposal at a time.
- Reject requires no reason; then show the next-best eligible ≥70%, if any.
- Identical rejected proposals do not recur without new evidence.
- Manual assignment remains possible.
