Each board follows the same real lifecycle: CSV preview, confirmation, imported
Library/reread and unknown Reading History, reconciliation categories, protected
Current vs Proposed values, decision actions, ambiguous identity, unsupported
date/rating evidence and committed Import History. The Accessibility XXXL board
shows consecutive scroll positions; a single viewport cannot show every enlarged
field/action. Content continues vertically rather than reducing its text size.

The fictional CSV is parsed and applied through the real repository. A protected
title is an actual subsequent manual edit. SQL safety counts are a debug-only
diagnostic, not manually assigned state. “QA inputs” is a debug-only fixture entry;
the release entry uses the native Files picker from Profile → StoryGraph Import.
No personal library, real CSV, secrets or cloud credentials are included.

Images are native simulator screenshots with proportional resizing and external
panel captions only. The provenance index records each original attachment,
application SHA, workflow run/artifact, device, timestamp, native dimensions and
SHA-256. Keep these source references when reviewing or reproducing evidence.

Human functional and visual approval remains pending. This evidence does not
certify physical-device Files providers or spoken VoiceOver, and does not resolve
or suppress the documented Foundation 107/148 findings deferred to Phase 12.
